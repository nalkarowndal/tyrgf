# 제품 요구사항

AURA Agent는 컴퓨터에 익숙하지 않은 한국어 사용자가 자연어로 요청하고 결과를 확인하는 개인용 AI 도우미다. 전체 요구사항은 USER_MASTER_PROMPT.md 원문을 기준으로 한다.

초기 성공 기준: 키 없이 모의 공급자로 설정 마법사와 스트리밍 대화를 실행하고, 대화가 재시작 후에도 남는다. Gemini/Groq/Ollama는 실제 어댑터를 제공하되 계정별 연결 테스트는 실 연결로만 판정한다. API 오류가 서버 전체를 종료시키지 않아야 한다.

한국어, 초보자 기본값, 도움말, 라이트/다크, 모바일·태블릿·데스크톱, 키보드 접근성이 필수다. 모든 노출 동작은 실제 동작하거나 준비 중으로 명확히 비활성화한다.

기술 스택은 SYSTEM_ARCHITECTURE.md, 단계별 요구사항과 미완료 게이트는 CODEX_PHASES.md에서 관리한다. 후속 목표는 안전한 승인 기반 도구 실행, 상태 유지 에이전트, 기억·스킬, MCP, Windows 배포다.
