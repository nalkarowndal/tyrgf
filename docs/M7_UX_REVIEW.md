# M7 초보자 UX 개선과 검수 (2026-10-17)

기준: USER_MASTER_PROMPT.md §3/§10.4/M7. 기존 화면과 API를 유지하면서 시작 안내, 입력 부담, 오류 복구, 키보드 이동을 개선했다. 시작 기준 c0aa470, work 브랜치. 신규 서버 API·의존성·외부 설치는 없다.

## 구현한 흐름
- 처음 사용 가이드 `/help`: AI 연결·첫 대화·파일·작업·기억·추가 도구의 행동 순서, 필요한 권한, 예상 결과, 실패 해결과 실제 화면 링크. 검색과 검색 결과 없음 복구. 모델 선택만으로 연결 성공을 표시하지 않는다.
- help-content.ts: 공통 설명과 기능 가이드의 중앙 원본. 기억과 MCP의 과거 ‘준비 중’ 설명을 현재 동작으로 정정했다.
- 초보자 모드: 작업·파일·기억을 우선 표시하고 나머지 메뉴는 ‘더 많은 도구’로 펼친다. 고급 모드에서 전체 메뉴 표시, 사용자 지정 숨김은 두 모드 모두 적용한다. 화면 모드 변경은 권한 부여가 아니다.
- 내장 프로젝트 MCP: 조회 도구를 한국어로 표시하고 파일/폴더 경로·검색어를 입력한다. 전송 입력과 스키마는 펼쳐 볼 수 있으며 승인 경계와 서버 검증은 동일하다. 외부 서버는 도구별 JSON 입력을 유지한다.
- 오류: 서버 연결/잘못된 응답을 한국어로 설명한다. 읽기 상태 조회만 사용자가 명시적으로 다시 요청할 수 있다. 연결 오류에서 입력을 보존하고 연결 정보 입력란으로 돌아갈 수 있다. 변경·승인 요청을 자동 재전송하지 않는다.
- 초기 설정 다시 보기: 설정 화면에서 다시 시작하고 Esc/닫기로 돌아온다. 기존 권한을 끄거나 ‘모두 꺼짐’으로 표시하지 않는다. 다시 보기 중 연결 설정을 저장한 경우 뒤쪽 연결 폼도 최신 저장값으로 다시 만든다. 저장 없이 닫으면 기존 폼 초안은 유지한다.
- 키보드: 모바일의 닫힌 메뉴는 inert, 열린 메뉴는 배경 inert·Tab 순환·Esc 닫기·열기 버튼 포커스 복원. 페이지 이동은 본문으로 포커스, 닫힌 대화상자는 호출 버튼으로 복원한다. 도움말 버튼은 Enter/클릭으로 펼치고 Esc로 닫는다.

## 실제 초보자 검수표 — 아직 사용자 실험 미실시
아래 자동 검증은 실제 사람의 이해도·소요 시간·도움 없이 완료 여부를 입증하지 않는다. 참가자가 설명 문서 없이 화면만 보고 수행하는 검수는 남아 있다.

| 시나리오 | 화면 안 안내/경로 | 개발 검증 근거 | 남은 검증 |
|---|---|---|---|
| API 연결 | 시작 가이드 → 설정 → 연결 테스트 | 모의 연결 E2E, 오류·입력 복구 fixture | 실 공급자 인증, 초보자 이해도 |
| 첫 대화 | 가이드 → 새 대화 | 기존 채팅 E2E | 실제 사용자의 첫 질문/결과 이해 |
| 무료 모델 선택 | 설정의 후보 모델·요금 링크·계정 동의 | 공급자 폼 테스트 | 계정 요금·실 한도, 실제 선택 이해 |
| 파일 접근 허용 | 가이드 → 파일 작업 | Linux 파일 권한·승인·복구 E2E | 실제 사용자의 경로 입력 |
| 작업 진행 확인 | 가이드 → 작업 관리 | 모의 계획의 실제 도구 실행 E2E | 실 모델 품질·진행/승인 이해 |
| 기억 삭제 | 가이드 → 기억 관리 | 기억 전체 삭제 E2E·권한 회귀 | 삭제 영향 이해 |
| 오류 해결 | 읽기 재조회·연결 정보 포커스 | 네트워크 실패/401 복구 E2E | 실제 오류에서 독립 복구 |
