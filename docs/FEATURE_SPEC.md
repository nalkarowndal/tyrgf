# 구현 기능 명세

## 구현됨 (M1–M2)
- 첫 실행 5단계: 환영 → 공급자 설정 및 연결 테스트 → 꺼진 권한 안내 → 첫 대화 예시 → 완료. 모의 연결은 실제 API 연결이 아니라고 표시.
- AI 연결: Gemini/Groq 키 등록·제거, Ollama 로컬 주소, 무료 후보 모델 선택, 계정 동의, 실 모델 목록 확인, 실 생성 연결 테스트. 키는 메모리에만 저장.
- 채팅: 세션 생성, UUID URL, 제목 변경, 검색, 삭제 확인, 스트리밍, 중단, Markdown/코드 복사, 최근 대화 컨텍스트, 사용자 질문 편집 및 답변 재생성.
- 텍스트 첨부: 24KB 이하 UTF-8 txt/md/csv/json/ts/tsx/js/py/log/html/css. 브라우저가 읽은 텍스트만 전송하며 서버 파일시스템 경로에 접근하지 않음. 이미지/PDF는 비지원.
- 데이터: SQLite 이력, 부분 응답 저장, 재시작 interrupted 복구, JSON 내보내기. 키는 export에서 제외.
- 화면: 초보자/고급, 메뉴 숨기기, 시스템/라이트/다크, 반응형, 오류 복구 안내.

## 정해진 동작
편집은 선택한 user 메시지와 이후 분기를 제거하고 새 질문으로 생성한다. 재생성은 마지막 user 질문 이후 응답만 교체한다. 같은 대화의 동시 생성/편집/삭제/이름변경은 409. 서로 다른 대화는 최대 2개 생성. 응답은 최대 120초·4,096 출력 토큰 요청·100,000 출력 글자로 제한한다. 첨부를 포함한 입력은 32,000글자 이하이며 설정된 컨텍스트 예산을 넘으면 내용 축소를 요청한다.

## 준비 중
Windows/macOS 파일 도구, 동적 브라우저 조작, 폴더 일괄 정리, 터미널, MCP 자동 계획 연동/REA 실행, 자동 백그라운드 요약, 백업 복원, Windows 설치 패키지. 메뉴는 준비 중 설명으로 연결되고 실행을 가장하지 않는다.

## M3 구현
Linux 폴더 권한과 텍스트 목록·읽기·생성·수정·삭제·복구, 1회 승인 미리보기, 실행 기록. 공개 HTTPS 본문 읽기와 정적 읽기 화면 캡처. 수동 도구 화면에서는 각 도구를 직접 선택한다. 세부 제한은 TOOL_MCP_DESIGN.md.

## M4 구현
작업 관리에서 목표·허용 폴더·실행 예산·외부 AI 전송 동의를 입력한다. 모델의 다음 동작 선택, 도구 관찰, 파일 쓰기/웹 읽기 개별 승인, 결과 검증, 일시중지·취소·재시작 후 재개를 제공한다. SQLite 작업/체크포인트와 실행 영수증으로 중복 변경을 방지한다. 모의 복합 작업은 고정 데모이며 실제 파일 도구를 사용한다. 상세 상태·검증 한계는 AGENT_DESIGN.md.

## M5 구현
기억의 목록·검색·분류·수정·승인·개별/전체 삭제·내보내기. 새 대화마다 승인 기억을 조회하며 삭제·수정 시 과거 파생 컨텍스트를 제외한다. 명시적 대화 요약은 원문 범위·해시와 공급자를 기록하고 초안으로 저장한다. 완료 작업에서 스킬 초안을 만들고 버전 검토·승인 후 새로운 작업에서 재사용한다. 세부 수명과 제한은 MEMORY_DESIGN.md.

## M6 외부 도구 연결
내장 Linux 프로젝트 MCP 실제 stdio 읽기/목록/검색, 사전 설치 GitHub·Serena·Repomix CLI 프로필 등록·실행 확인·도구 발견·선택 권한·JSON 입력 승인·결과 기록·해제. 실행 파일 해시와 승인 세대/스키마/입력을 확인한다. 외부 CLI는 OS 계정 권한이며 앱이 자동 설치/격리하지 않는다. 외부 서비스 실제 연결은 미검증, 자동 Agent/Skill 연동과 REA는 후속이다.


## M7 UX 개선
처음 사용 가이드 검색과 행동 링크, 초보자/고급 메뉴 구분, 초기 설정 재실행, 실제 권한 상태를 오인하지 않는 안내, 내장 MCP 파일/검색 입력, 읽기 조회 재시도와 연결 정보 포커스, 모바일 메뉴와 dialog 키보드 복원. 서버 권한과 승인 정책은 바꾸지 않는다. 실제 초보자 이해도 검수는 별도 미완료이며 M7_UX_REVIEW.md에 검수표를 제공한다.
