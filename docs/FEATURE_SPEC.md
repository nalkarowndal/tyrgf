# 구현 기능 명세

## 구현됨 (M1–M2)
- 첫 실행 5단계: 환영 → 공급자 설정 및 연결 테스트 → 꺼진 권한 안내 → 첫 대화 예시 → 완료. 모의 연결은 실제 API 연결이 아니라고 표시.
- AI 연결: Gemini/Groq 키 등록·제거, Ollama 로컬 주소, 무료 후보 모델 선택, 계정 동의, 실 모델 목록 확인, 실 생성 연결 테스트. 키는 메모리에만 저장.
- 채팅: 세션 생성, UUID URL, 제목 변경, 검색, 삭제 확인, 스트리밍, 중단, Markdown/코드 복사, 최근 대화 컨텍스트, 사용자 질문 편집 및 답변 재생성.
- 텍스트 첨부: 24KB 이하 UTF-8 txt/md/csv/json/ts/tsx/js/py/log/html/css. 브라우저가 읽은 텍스트만 전송하며 서버 파일시스템 경로에 접근하지 않음. 이미지/PDF는 비지원.
- 데이터: SQLite 이력, 부분 응답 저장, 재시작 interrupted 복구, JSON 내보내기. 키는 export에서 제외.
- 화면: 초보자/고급, 메뉴 숨기기, 시스템/라이트/다크, 반응형, 오류 복구 안내.

## 정해진 동작
편집은 선택한 user 메시지와 이후 분기를 제거하고 새 질문으로 생성한다. 재생성은 마지막 user 질문 이후 응답만 교체한다. 같은 대화의 동시 생성/편집/삭제/이름변경은 409. 서로 다른 대화는 최대 2개 생성. 응답은 최대 120초·4,096 출력 토큰 요청·100,000 출력 글자로 제한한다. 첨부를 포함한 입력은 32,000글자 이하이며 설정된 컨텍스트 예산을 넘으면 내용 축소를 요청한다.

## 준비 중
에이전트 모드, Windows/macOS 파일 도구, 동적 브라우저 조작, 폴더 일괄 정리, 터미널, GitHub, MCP, 기억, 스킬, 자동 요약, 백업 복원, Windows 설치 패키지. 메뉴는 준비 중 설명으로 연결되고 실행을 가장하지 않는다.

## M3 구현
Linux 폴더 권한과 텍스트 목록·읽기·생성·수정·삭제·복구, 1회 승인 미리보기, 실행 기록. 공개 HTTPS 본문 읽기와 정적 읽기 화면 캡처. 각 도구는 직접 선택하며 AI 자동 실행은 없다. 세부 제한은 TOOL_MCP_DESIGN.md.
