# AURA 사용 설명서

## 실행
현재는 개발·로컬 검증 버전이며 Windows 설치 프로그램은 아직 없다. Node.js 24 이상과 npm이 필요하다. 프로젝트 폴더에서:

```sh
npm ci
npm run build
npm start
```

브라우저에서 http://127.0.0.1:4317 을 연다. 종료하려면 실행 터미널에서 Ctrl+C를 누른다. 개발자는 npm run dev를 사용할 수 있다. 다른 컴퓨터나 인터넷에서 접근하도록 서버를 공개하지 않는다.

## AI 연결 없이 사용
처음 설정에서 체험용 모의 AI → 연결 테스트 → 다음 → 완료. 정해진 체험 안내가 답변으로 나타난다. 번역/요약 등 실제 AI 작업을 수행한 것이 아니다.

## 실제 AI 연결
설정의 AI 연결에서 Gemini, Groq 또는 설치된 Ollama를 고른다. API 키는 비밀번호처럼 다룬다. 무료 계정인지 공급자 콘솔에서 확인하고 대화 전송에 동의한다. 모델 목록과 연결 테스트를 확인한다. 요금제가 유료이면 앱에서 실제 과금을 차단하지 못하므로 무료 계정만 사용한다. 정확한 잔여 한도는 공급자 콘솔에서 확인한다.

## 대화
새 대화 → 메시지 입력 → 전송. 답변 중 네모 버튼으로 중단할 수 있다. 코드는 코드 복사, 일반 메시지는 복사 버튼을 이용한다. 답변 다시 생성은 마지막 질문에 새 답변을 만들며 기존 답변을 교체한다. 질문 수정은 그 뒤의 대화를 새 분기로 바꾸므로 내용을 먼저 확인한다.

왼쪽 검색창은 제목과 본문에서 찾는다. 대화 상단 연필로 이름을 바꾸고 휴지통으로 삭제한다. 설정에서 대화 전체를 JSON으로 내보낼 수 있다. 내보낸 파일에는 대화 내용이 있으므로 안전하게 보관한다. 현재 가져오기/복원은 준비 중이다.

클립 버튼으로 24KB 이하 UTF-8 텍스트를 첨부할 수 있다. PDF·사진은 지원하지 않는다. 클라우드 AI를 선택하면 첨부 텍스트도 그 서비스에 전송된다. 첨부 파일이 컴퓨터에 명령을 실행하지는 않는다.

## 오류 해결
- 키/권한 오류: 공급자 콘솔에서 키를 재발급하고 설정에서 다시 입력한다.
- 무료 한도 오류: 공급자 콘솔을 확인하고 기다린다. 앱이 다른 유료 모델로 바꾸지 않는다.
- Ollama 연결 오류: Ollama가 실행 중인지, 선택한 로컬 모델이 설치되어 있는지 확인한다.
- 입력이 너무 길다는 안내: 텍스트를 나누거나 고급 설정의 대화 길이 예산을 늘린다. 최대 32,000글자다.
- 답변 중 연결 끊김: 저장된 부분 응답을 확인하고 다시 생성한다. 재시작 뒤에는 중단됨으로 표시된다.
- 앱 연결 만료: 브라우저를 새로고침한다. 서버를 다시 시작했다면 API 키도 다시 입력한다.

대화와 설정은 프로젝트 .data 폴더에 저장된다. 파일·웹 읽기 도구의 권한과 실행 기록도 로컬에서 관리한다. 기억과 스킬은 관리 화면에서 검토·승인 후 사용한다. MCP는 별도 연결 화면에서 수동 조회 호출을 제공하며, 동적 브라우저 조작은 준비 중이다. 같은 OS 사용자 권한의 다른 프로그램까지 격리하는 제품은 아니다.

## 파일 작업 (Linux)
1. 파일 작업 메뉴에서 폴더 전체 경로를 입력한다. 기본 전용 폴더는 허용할 때 만들어진다.
2. 읽기만 필요하면 수정 체크를 끈다. 생성·수정·삭제하려면 체크하고 이 폴더 허용을 누른다.
3. 상대 경로를 비워 목록을 보거나 파일 이름을 입력해 읽는다. UTF-8 텍스트 24KB까지 지원한다.
4. 내용을 적고 저장 미리보기 또는 삭제 미리보기를 누른다. 전후 내용과 경로를 확인하고 이번 한 번 승인을 누른다.
5. 실행 기록의 복구 미리보기는 같은 세션에서 현재 파일이 바뀌지 않았을 때 사용할 수 있다. 전후 내용 보기와 원본 복구 위치는 재시작 후에도 기록에 남는다. 원본 숨김 복구 파일은 자동 삭제하지 않는다. 작업 중 다른 프로그램으로 폴더를 이동하지 않는다.

권한 해제는 대기 요청도 취소한다. 앱을 재시작하면 모든 폴더 권한이 꺼진다. Windows/macOS 파일 작업은 준비 중이다.

## 공개 웹페이지 읽기
브라우저 자동화 메뉴에서 웹 읽기 권한을 켜고 공개 HTTPS 주소를 입력한다. 미리보기에서 주소 전체가 사이트로 전송됨을 확인하고 승인한다. 결과는 제목·본문·읽기 화면 캡처로 표시한다. 원본 사이트의 이미지/레이아웃/동적 콘텐츠는 제외한다. 로그인·입력·클릭·다운로드·자동 이동은 지원하지 않는다. 리다이렉트 오류이면 최종 공개 주소로 새 요청을 만든다. 실행 중단 버튼으로 취소할 수 있다. Chromium 설치가 필요하며 CHROMIUM_PATH로 경로를 지정할 수 있다.

## 복합 작업과 재개 (M4, Linux)
1. 파일 작업에서 작업용 폴더를 허용한다. 보고서를 만들려면 수정 권한도 켠다.
2. 작업 관리에서 목표와 폴더, 도구 실행 횟수를 선택한다. 클라우드 모델은 목표와 도구 결과 전송에 별도로 동의해야 한다.
3. 작업 시작을 누르면 진행한 단계와 근거가 표시된다. 파일 저장이나 웹 연결은 대상·내용을 확인하고 체크한 뒤 이번 한 번 승인한다. 거절하면 작업이 취소된다.
4. 일시중지 후 작업 재개로 이어갈 수 있다. 서버를 재시작했다면 원래 폴더를 다시 허용하고 원래 AI 모델과 키를 복원한다. 이미 확인된 파일 저장은 반복하지 않는다. 만료된 승인은 다시 확인한다.
5. 완료 시 검증 근거와 실제 파일을 확인한다. 파일이 바뀌거나 저장 결과가 불확실하면 결과 확인 상태로 멈춘다. 도구 실행 기록에서 원본 복구 위치를 확인한다. AI 답변의 의미적 정확성은 직접 검토한다.

AI 없이 체험하려면 모의 공급자를 선택하고 폴더 바로 아래에 txt 또는 md 파일 하나를 준비한다. 목표 문구와 무관하게 목록 조회 → 첫 텍스트 읽기 → aura-report.md 저장을 실행하는 고정 데모다. 파일은 실제 생성되지만 보고서는 AI 요약이 아닌 발췌다.

작업은 동시에 하나만 실행하며 활성 실행은 회당 2분, 계획 호출은 작업당 12회다. 반복 오류는 2회까지 재개하고 이후 중단한다. 작업 기록에는 읽은 파일 본문이 남을 수 있으며 개별 기록 삭제 기능은 아직 없다.

## 기억 관리
기억 제목·분류·내용을 입력하고 초안 저장을 누른다. 저장된 내용을 확인한 뒤 이 버전 사용 승인을 누르면 새 대화를 포함한 다음 요청에 반영된다. 클라우드 AI에는 기억도 전송되므로 비밀번호와 키는 저장하지 않는다. 검색·분류로 찾고, 수정한 내용은 다시 승인한다. 전체 내보내기는 JSON 파일을 내려받는다. 개별 또는 전체 삭제는 확인창에서 결정한다.

기억을 삭제하거나 수정하면 과거 답변에서 삭제한 정보가 다시 전달되지 않도록 기존 대화의 맥락과 요약을 다음 요청에서 제외한다. 과거 대화는 화면에 남지만 필요한 맥락은 새 질문으로 설명해야 한다. 이미 외부에 보낸 정보와 내려받은 사본은 회수하지 않는다.

대화에서 요약 만들기에서 원문 대화를 선택한다. 실제 AI는 요약 초안을 만들며, 모의 AI는 ‘모의 발췌’를 만든다. 실패해도 원문은 유지된다. 원문 변경으로 요약 승인이 거절되면 새 요약을 만들거나 내용을 직접 수정해 사용자 기억으로 저장한다. 요약은 최대 24,000자 원문만 처리한다.

## 스킬 관리
작업 관리에서 완료된 작업의 스킬 초안으로 저장을 누른다. 스킬 관리에서 목적·단계·사용 도구·필요한 권한·검증 방법을 읽고 확인란과 현재 버전 승인을 누른다. 이 스킬로 새 작업을 열어 목표·폴더·전송 동의를 지정한다. 파일 변경과 웹 연결은 매번 따로 승인한다.

스킬을 수정하면 버전이 바뀌고 승인도 해제된다. 삭제하거나 수정한 버전을 사용하던 작업은 계속 실행할 수 없으므로 최신 버전을 검토하고 새 작업을 만든다. 마지막 실행 결과에서 진행 상태를 확인할 수 있다. 모의 공급자는 기존 고정 데모이며 스킬을 고르면 허용 도구 범위도 적용한다.


## 외부 도구 연결 (M6)
1. 파일 작업에서 폴더를 허용하고 외부 도구 연결 메뉴를 연다. AURA 프로젝트 MCP는 추가 설치 없이 Linux에서 실제 파일을 읽는다.
2. 서버 종류와 폴더를 골라 서버 등록을 누른다. GitHub/Serena/Repomix는 공식 안내를 통해 먼저 CLI를 설치하고 실행 파일의 절대 경로를 입력한다. 앱은 자동 설치하지 않는다.
3. 연결 검토에서 실행 범위를 확인한 뒤 확인하고 연결 테스트를 누른다. 외부 서버는 OS 계정 권한으로 실행되므로 출처를 신뢰해야 한다. GitHub PAT는 여기에서만 입력하고 Groq 키를 사용하지 않는다.
4. 발견된 도구 중 사용할 항목을 체크하고 도구 권한 저장을 누른다. 지원 범위 밖 도구는 허용할 수 없다.
5. 실행할 도구를 고르고 입력 형식을 펼쳐 JSON을 작성한다. 내장 읽기 예: `{"path":"hello.txt"}`, 목록 예: `{"path":""}`, 문자열 검색 예: `{"path":"hello.txt","query":"찾을 말"}`.
6. 실행 미리보기에서 입력을 확인하고 한 번 실행하거나 거절한다. 결과와 오류는 실행 기록에 남는다. 결과는 AI로 자동 전송되지 않는다.
7. 연결 해제로 실행 중 호출과 대기 승인을 중단한다. 재시작 후에는 폴더를 다시 허용하고 같은 폴더를 선택해 연결한다. 실행 파일이 변경되면 등록을 삭제한 뒤 공식 출처를 확인해 다시 등록한다.

연결 실패 시 실행 파일·Node/Python/언어 서버 설치·네트워크·GitHub PAT 권한을 확인한다. 서버가 도구 50개/수신 1MiB 제한을 넘거나 20초 안에 응답하지 않아도 실패한다. 이 버전은 수동 조회 호출이며 자동 작업 계획/스킬, Repomix 코드 패킹, REA 실행은 아직 연결하지 않는다. 실제 GitHub/Serena/Repomix 연결은 개발 환경에서 검증하지 않았다.


## 처음 사용 가이드와 키보드
처음 사용 가이드에서 기능 이름을 검색하고 안내에 따라 실제 화면으로 이동한다. 초보자 모드의 ‘더 많은 도구’를 펼치면 웹·스킬·외부 도구 등이 나타난다. 설정의 고급 모드로 바꾸고 일반 설정 저장을 누르면 전체 메뉴가 보인다. 메뉴 표시를 바꾸어도 도구 권한은 바뀌지 않는다.

설정 → 처음 설정 다시 보기로 5단계 안내를 다시 열 수 있다. 닫기/Esc로 돌아오며 기존 파일·웹·MCP 권한은 유지된다. 안내 중 저장한 AI 설정은 돌아온 설정 화면에도 반영된다. 모의 AI는 실제 모델 연결이나 무료 계정 확인을 대신하지 않는다.

모바일 메뉴는 Tab/Shift+Tab으로 이동하고 Esc로 닫는다. 창을 닫으면 열었던 버튼으로 돌아간다. 도움말 아이콘은 Enter로 펼치고 Esc로 닫는다. 읽기 목록의 연결 오류는 다시 불러오기를 누른다. 실행 요청 오류는 먼저 기록을 확인하며 앱은 변경 요청을 자동 재전송하지 않는다.

내장 MCP는 읽을 파일 경로나 폴더 경로, 필요한 검색어를 입력하면 된다. JSON을 직접 작성할 필요는 없다. 미리보기의 실제 전송 입력은 계속 확인할 수 있다.


## 설치·백업·복원
Windows 배포 후보의 설치, 암호화 백업과 복원, 자동 시작, 수동 업데이트, 앱 종료 방법은 [설치와 데이터 관리](DEPLOYMENT_GUIDE.md)를 참고하세요. Windows 런타임 자동 검수는 통과했으며 설치 GUI 검수·코드 서명은 남아 있습니다.
