# 도구·MCP 설계

M3는 수동 파일 도구와 공개 웹 읽기를 제공한다. M4 작업 관리가 제한된 다음 동작 선택과 동일한 승인 체계를 사용한다. 외부 MCP는 M6 예정이다. 개발에 사용한 GitHub/Exa/Context7/Canva connector는 제품 내부 연결과 별개다.

## 레지스트리와 승인
packages/shared/src/tools.ts에 도구 ID, 한국어 설명, 입력 파라미터, 출력 형식, 권한, 위험, 실행 환경, 지원 상태를 등록한다. Zod discriminated union으로 변경 입력을 검증하고 ToolService가 미리보기·실행·검증·기록을 관리한다. file.read, file.write, file.delete, browser.read를 지원한다.

권한은 서버 메모리에만 있고 재시작하면 꺼진다. 파일 읽기는 폴더별 읽기 권한, 변경은 쓰기 권한과 개별 승인이 필요하다. 웹 읽기는 별도 권한과 주소별 승인이 필요하다. 승인 요청은 서버가 저장한 입력·대상·전후 내용·fingerprint에 묶이며 승인 API는 ID와 빈 본문만 받는다. 만료 10분, 미처리 요청 최대 20개, 도구 실행 동시 1개. SQLite 조건부 UPDATE로 한 번만 실행권을 획득한다. 거절/권한 철회/재시작/만료 후 재사용할 수 없다.

## 파일
Linux /proc/self/fd와 O_NOFOLLOW 디렉터리 핸들로 루트와 경로 요소를 고정한다. 상대 경로만 허용하며 숨김 파일, symlink, hardlink, 특수 파일, Windows 장치/ADS 이름, 잘못된 UTF-8, NUL, 24KB 초과 파일을 차단한다. 폴더 목록은 500개까지 검사한다. 읽기는 AI에 자동 전송하지 않는다.

기존 파일은 승인된 inode/내용/mtime/부모와 비교한다. 변경 시 원본을 같은 폴더의 .aura-recovery-<실행ID>/original로 먼저 이동하고 다시 검증한다. 새 내용은 임시 파일에 fsync 후 배타적 link로 게시하므로 중간에 다른 파일이 생기면 덮어쓰지 않는다. 원본 복구 경로를 실행 전에 DB에 기록하고 실제 원본 inode를 유지한다. 실패 시 원래 경로가 비어 있을 때만 원본을 되돌린다. 성공 후에도 원본 복구 파일은 자동 삭제하지 않는다.

전후 텍스트는 SQLite에도 저장한다. 복구 버튼은 현재 fingerprint가 실행 직후와 같고 같은 세션의 폴더 권한이 있을 때 새 승인 요청을 만든다. 재시작/크래시로 불확실한 작업은 interrupted로 표시하고 자동 재실행하지 않는다. 사용자는 전후 기록과 원본 복구 경로로 확인한다. 숨김 복구 파일은 저장 공간을 사용하며 정리 UI는 후속 작업이다.

권한은 경로로 선택한 디렉터리의 정체성을 승인한다. 실행 중 위치 재검사를 하지만 같은 OS 사용자 권한의 악성 프로세스가 마지막 검사 직후 폴더를 이동시키는 행위까지 격리하지는 못한다. 열린 디렉터리의 정체성은 이동 뒤에도 유지된다. OS 샌드박스 보장은 아니며 작업 중 외부 폴더 이동은 피해야 한다. Windows/macOS 파일 도구는 안전한 네이티브 구현 전 차단한다.

## 웹 읽기
공개 HTTPS:443만 허용한다. 인증정보·내부/예약 IP·특수 hostname·별도 포트·리다이렉트는 차단한다. DNS 전체 응답을 검사하고 검증된 IP에 연결을 고정하며 원래 Host와 TLS SNI/인증서 검증을 유지한다. 쿠키·사용자 세션·API 키를 보내지 않는다. 한 번 승인한 URL 전체가 해당 사이트로 전송된다.

20초 작업 제한, 10초 socket 제한, 1MiB UTF-8 HTML/text 제한. 외부 HTML은 parse5로 파싱하여 제목·본문 최대 24,000자를 추출한다. 원격 HTML 자체는 Chromium에 주입하지 않는다. 이스케이프한 텍스트만 새 오프라인 컨텍스트에서 렌더링하고 JS·서비스워커·네트워크·다운로드를 차단한다. PNG는 원본 웹 디자인이 아니라 읽기 화면의 캡처다. 실행 취소/권한 철회는 fetch와 브라우저에 전달한다.

로그인·입력·클릭·페이지 이동·사이트 원본 캡처, 폴더 이동/일괄 정리, 명령 실행은 준비 중이다. 웹 읽기의 라이브 외부 연결은 개발 환경 DNS 제한으로 미검증이며 DNS/HTTP fixture와 실제 Chromium 렌더링을 구분해 기록한다.

## MCP 후속
서버 출처·버전·설치 조건·제공 도구·요구 권한·신뢰 상태를 저장한다. 설치/시작은 사용자 승인 후 수행한다. 초기에는 읽기 전용 도구부터 허용한다. GitHub MCP, Serena, Repomix, 선택 REA는 M6에서 실제 호출을 검증한다.
