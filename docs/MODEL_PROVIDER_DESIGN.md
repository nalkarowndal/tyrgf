# 공급자와 무료 정책

구현: packages/shared/src/contracts.ts registry, apps/server/src/providers.ts.
공통 인터페이스: validateProvider, listModels, streamReply → delta/usage 이벤트. 실제 테스트는 모델 목록 포함 여부와 짧은 생성 응답을 모두 확인한다. 모의 공급자는 simulated=true이며 정해진 체험 안내만 생성한다.

## 모델 선택
Gemini/Groq 후보는 공식 문서 확인 목록으로 중앙 관리한다. 공급자 모델 API와 후보 목록의 교집합만 UI 목록에 제시한다. 사용자가 선택한 후보라도 계정에서 사용할 수 없으면 연결 테스트가 실패한다. 앱 전체 여러 파일에 모델 이름을 중복하지 않는다. Ollama는 설치된 모델을 조회하고 cloud 이름·remote_host·remote_model을 차단한다. 추론 직전 /api/show로 로컬 모델 여부를 확인한다.

## 무료 우선
클라우드 호출은 externalConsent와 freeConfirmed 및 키가 모두 필요하다. freeConfirmed는 사용자의 계정 확인이며 계정 과금 차단 기술이 아니다. 프로그램은 무료 후보 외 모델, 임의 API URL, 자동 공급자/유료 전환, 유료 도구를 허용하지 않는다. 공급자 변경 시 동의가 초기화된다. 정확한 잔여 한도는 표시하지 않는다. 누적 요청과 토큰 사용량(보고값 또는 글자 수 기반 추정)만 표시한다. 연결 테스트도 집계한다.

429는 Retry-After가 0~3초인 경우 같은 요청을 한 번만 재시도한다. 긴 제한은 기다리도록 안내하며, 일부 답변이 나온 이후 생성 전체를 자동 재시도하지 않는다. 서버 전체 생성 시간은 120초, 연결 테스트는 30초, 목록은 15초다. HTTP redirect를 거부한다.

## 컨텍스트
최근 전체 메시지를 글자 예산 안에서 보존하며 첫 메시지는 user가 되도록 맞춘다. 오래된 메시지를 제외하면 UI notice를 보낸다. assistant의 미완료/오류 응답은 후속 컨텍스트에 포함하지 않는다. 토큰 단위 정확한 예산·과거 요약은 M5에 남긴다. 도구 호출은 현재 어댑터에서 지원하지 않으며 모델이 가능해도 앱 기능으로 노출하지 않는다.
