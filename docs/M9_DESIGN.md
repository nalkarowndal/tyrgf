# M9 배포 설계

목표: 개발 환경 없이 Windows x64에서 기존 로컬 앱을 실행하고, 사용자 데이터를 암호화해 옮길 수 있게 한다. 사용자의 M9 진행 지시에 따라 기존 앱을 유지하며 네이티브 방식으로 구현한다.

## 배포
Electron은 별도 런타임/보안 표면이 크고, Node SEA는 동적 MCP/Playwright 자원 처리가 복잡하다. Node 24 Windows 런타임 + 번들 서버 + 기존 웹 UI를 포함한 per-user NSIS 설치/portable ZIP을 사용한다. 브라우저는 시스템 기본 브라우저로 연다. 설치는 관리자 권한 없이 LocalAppData/Programs, 데이터는 별도 LocalAppData/AURA Agent/data. 자동 시작은 기본 꺼짐이며 설치 옵션으로만 선택한다. 업데이트는 앱 종료·백업 후 새 설치 파일로 수동 적용, 자동 다운로드/실행 없음. 제거는 앱 파일과 바로가기만 지우고 데이터를 보존한다. 서명 인증서와 실제 Windows 실행 환경은 없으므로 unsigned/실행 미검증을 명시한다.

## 운영 경계
파일 도구는 Linux만 지원한다. Windows에서 우회 구현하지 않으며 UI의 미지원 안내를 유지한다. 웹 스냅샷은 패키지에 Playwright 엔진을 임의 다운로드하지 않고 설치된 Edge를 사용할 수 있게 한다. 데이터 경로 단위의 localhost 실행 잠금으로 앱과 백업 도구의 동시 DB 접근을 차단한다. 키는 기존 메모리 보관을 유지해 종료 시 소멸하며 저장/백업하지 않는다.

## 백업/복원
앱을 종료한 뒤 전용 Windows 바로가기에서 파일 선택과 암호 입력으로 실행한다. 대화/메시지, 기억, 스킬, 화면 설정을 버전 있는 JSON으로 저장하고 scrypt + AES-256-GCM으로 암호화한다. 입력/파일 크기를 제한하고 변조/오류 암호는 원본 변경 전에 거절한다. 백업 파일 덮어쓰기 금지. 복원은 별도 임시 DB에 검증된 데이터만 작성해 교체한다. 기존 데이터는 교체 전 암호화 안전 사본으로 보존한다. 대화 API JSON 내보내기는 암호화 백업과 다름을 안내한다.

복원 데이터의 기억/스킬은 검토 대기로, 공급자는 모의/외부 동의 꺼짐으로 초기화한다. 실제 파일, 실행 기록/진행 작업, MCP 프로그램/프로필/승인, API 키와 도구 권한은 이동하지 않는다. 이런 제외 사항과 현재 데이터 교체를 복원 화면에서 확인한다. 요약 기억은 사용자 검토용 텍스트 초안으로 바뀐다. 오래된 문맥 제외 경계는 보존한다.

## 검증
백업 왕복/키 비포함/암호·변조·버전·제한·참조 오류/기존 데이터 보존/잠금 충돌 테스트. 소스와 번들 런타임 모두 실제 HTTP 모의 대화·종료·내장 MCP 호출을 검사한다. Windows 바이너리 공식 SHA256 검증, 실제 설치 파일 생성과 구성 검사. Linux 검증을 Windows 실행 증거로 취급하지 않는다.
