# 처음 설정

1. 실행 후 ‘설정 시작’을 누른다. 예시는 질문, 번역, 대화 관리다.
2. API 키가 없으면 ‘체험용 모의 AI’를 유지하고 ‘연결 테스트’를 누른다. 실제 AI가 아니라는 안내를 확인한다.
3. 실제 AI는 Gemini/Groq 선택 → ‘API 키 발급하기’ → 키 붙여넣기 → 공급자 요금·한도 확인 → 무료 계정 확인 및 외부 대화 전송 동의 → 모델 목록 확인 → 연결 테스트 순서다. 키를 발급받는 것은 사용자 계정에서 직접 수행한다.
4. Ollama는 PC에서 먼저 설치하고 로컬 모델을 받아야 한다. 모델 목록에서 선택하고 연결 테스트한다. cloud 모델은 사용할 수 없다.
5. 도구 권한이 모두 꺼져 있음을 확인한다. 현재는 읽기/수정 권한을 켜는 기능이 없으며 준비 중이다.
6. 예시 질문을 읽고 완료 화면에서 선택 AI와 저장 위치를 확인한 뒤 AURA 시작하기를 누른다.

설정은 언제든 왼쪽 메뉴에서 바꿀 수 있다. 연결 테스트가 실패하면 설명에 따라 키/모델/인터넷/Ollama 실행 상태를 확인한다. 모의 AI로 전환하면 외부 연결 없이 계속 체험할 수 있다. 키는 서버 종료 시 삭제되므로 다음 실행 때 다시 입력한다.
