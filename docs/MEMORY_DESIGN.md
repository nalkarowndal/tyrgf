# 기억과 스킬 (M5)

현재 작업 기억은 M4 작업 레코드, 최근 대화는 SQLite 메시지로 유지한다. M5는 KnowledgeStore의 사용자 기억과 명시적 대화 요약, SkillsStore의 검토된 작업 절차를 추가한다. 단일 로컬 사용자·기존 SQLite이며 임베딩 서비스나 별도 유료 API를 추가하지 않는다.

## 기억의 수명
기억은 제목·분류·본문·출처·생성/수정 시각·버전·승인 시각과 활성 상태를 보관한다. 최대 100개, 본문 2,000자다. 사용자 입력과 AI 요약은 모두 초안으로 저장한다. 현재 버전 승인 후에만 대화에 사용한다. 수정하면 버전을 올리고 승인을 해제한다. 요약을 사람이 수정하면 사용자 작성 기억으로 바꾸되 원문 대화 참조를 유지한다.

목록·제목/본문 검색·분류 필터·수정·개별/전체 삭제·JSON 내보내기를 제공한다. 매 대화 요청에서 DB의 현재 승인 기억만 읽는다. 컨텍스트 길이는 min(6,000자, 대화 예산의 절반)이며 최근 생성 항목부터 넣고 초과 항목 수를 안내한다. 본문은 신뢰되지 않는 참고 데이터로 사용자 메시지에 붙이며 저장된 원문 메시지를 덮어쓰지 않는다. 대화 화면은 클라우드 사용 시 기억도 전송됨을 안내한다. 기억은 작업 도구 실행 권한이나 시스템 지시가 아니다.

## 삭제·수정과 파생 정보
기억 삭제·수정은 진행 중 대화/요약 요청을 중단하고, knowledge_meta epoch를 증가시키며 각 대화의 context_boundaries를 현재 메시지까지 옮긴다. 과거 답변이나 요약이 삭제한 기억을 다시 모델에 보내지 않도록 해당 경계 이전 메시지는 후속 요청에 넣지 않는다. 모든 요약도 사용을 중단한다. 저장된 과거 대화는 화면에 남으며 새 질문에서 필요한 맥락을 다시 설명해야 한다. 이미 전송한 정보, 사용자가 직접 새로 입력한 정보, 내보낸 사본과 외부 백업의 삭제를 보장하지 않는다. 삭제를 포렌식 완전 삭제로 취급하지 않는다.

## 요약
기억 관리에서 대화를 선택해 명시적으로 요청한다. 현재 유효 범위의 완료 메시지를 최대 24,000자 읽고, 60초 안에 최대 2,000자 결과를 받는다. 원문 sessionId/throughSeq/SHA256과 공급자·모델·모의 여부를 저장한다. 원문 삭제·수정, 기억 변경, 공급자 설정 변경이 감지되면 저장을 거부한다. 실패해도 원문은 그대로 남는다. 새 메시지 추가는 이전 원문 범위 요약을 무효화하지 않는다. 사용할 때도 원문 해시를 재검사한다. 질문 수정·답변 재생성에서 잘려 나갈 범위를 포함한 요약은 원문을 실제 삭제하기 전 해당 요청의 기억 선택 시점부터 제외한다.

모의 공급자는 원문 일부를 ‘모의 발췌’로 저장하며 실제 AI 요약이라고 표시하지 않는다. 실제 모델의 요약도 초안이며 사용자가 검토·승인해야 한다. 자동 백그라운드 요약·민감정보 추출은 구현하지 않았다.

## 스킬
완료된 M4 작업에서 이름·목적·성공한 실행 순서·사용 도구·검증 방법을 초안으로 저장한다. 파일 본문·승인 run ID를 복사하지 않는다. 원본 작업 ID, 버전, 승인 버전, 시각을 저장하고 연결된 최신 작업의 결과를 조회한다. 필요한 권한은 도구 목록에서 서버가 계산한다. 최대 100개, 단계 8개다.

사용자가 현재 버전을 확인·승인해야 새 작업에서 선택할 수 있다. 수정하면 승인 해제, 삭제하면 재사용 불가다. 새 작업은 skillId/skillVersion만 참조하고 매 계획·실행·승인 시 현재 승인 버전을 검사한다. 승인된 도구 목록 밖의 모델 동작은 실행하지 않는다. 일반 도구 기록 화면에서 승인하더라도 공통 ToolService 승인 경계가 연결된 작업 상태·스킬 버전·연결·폴더 권한을 다시 검사한다. 실제 공급자에는 절차를 계획의 참고 자료로 전달한다. 의미적으로 정확히 같은 절차를 보장하는 결정적 매크로는 아니다. 모의 공급자는 기존 고정 데모이며 스킬의 도구 제한은 동일하게 적용한다.

새 작업에는 폴더와 목표를 다시 지정하고 클라우드 전송에 동의한다. 스킬 승인은 폴더 권한·파일 쓰기/웹 읽기 개별 승인을 대체하지 않는다. 모델이 자의적으로 스킬을 활성화하거나 승인 상태를 고칠 수 있는 API는 제공하지 않는다. 기억은 대화에 적용하고, 작업에는 사용자가 선택한 스킬만 적용한다.

## 저장/연결
schema user_version=4. memories/skills JSON payload, knowledge_meta epoch, context_boundaries FK→sessions. GET /api/memories, /context, /export; POST 생성, /summarize, /delete-all, /:id/update|approve|delete. GET /api/skills; POST /from-task, /:id/update|approve|delete. 쓰기에는 기존 Host/Origin/CSRF 경계를 사용한다.
