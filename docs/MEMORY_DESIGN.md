# 기억과 스킬 설계

현재 구현: SQLite 대화 이력 및 최근 메시지 컨텍스트. 동일 세션 내에서만 최근 메시지를 전달하며, 새 대화로 자동 장기 기억이 이동하지 않는다. 과거 요약·사용자 기억·스킬은 준비 중으로 표시한다.

M5 목표: memory(id, category, content, source, created_at, updated_at, approved_at)와 skill(id, name, purpose, steps, tools, permissions, verification, version, last_result). 사용자 작성 또는 명시적 승인 후에만 장기 기억/스킬을 활성화한다. 민감 정보 자동 추출은 기본 비활성.

목록·검색·분류·수정·개별/전체 삭제·내보내기를 제공한다. 생성 요청 시 DB의 현재 활성 기억만 조회해 삭제된 기억을 다시 쓰지 않는다. 요약은 범위와 소스 메시지 버전을 저장하고 실패하면 최근 원문으로 복구한다. 스킬 생성/수정은 검토 초안으로 저장하고 자동 적용하지 않는다.

검증: 세션 간 명시적 기억 재사용, 삭제 후 조회·컨텍스트에서 제외, 출처 추적, 요약 실패 복구, 스킬 버전 승인 이전 실행 금지. 현재 M2의 컨텍스트 제외 안내를 요약 성공처럼 표시하지 않는다.
