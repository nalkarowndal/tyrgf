# M4 — 영속 작업 에이전트
기준 aa2a3a5. 명세 USER_MASTER_PROMPT.md / AGENT_DESIGN.md.

1. LangGraph StateGraph의 계획→도구→검증 반복과 SQLite 체크포인트 저장. 별도 작업 레코드가 목표, 공급자/모델, 폴더 정체성, 단계, 관찰, 승인 run ID, 예산을 영속 보관한다. 노드 재실행은 저장된 단계와 실행 영수증으로 중복 방지한다.
2. 실제 공급자는 기존 streamReply로 다음 동작을 엄격한 JSON 계약으로 선택한다. 모의 공급자는 목록→첫 텍스트 읽기→보고서 저장→검증의 고정 데모이며 실제 AI로 표시하지 않는다. 최대 8회 도구, 12회 모델, 활성 실행 120초/회, 전체 모델 입력 길이 제한. 자동 유료 전환 없음.
3. 폴더는 이미 허용한 것 중 하나만 선택한다. 외부 AI로 목표/도구 결과 전송은 작업별 동의 필요. 공급자/모델 설정이 변경되면 기존 작업 실행을 막고 원래 설정 복원 안내. 파일 쓰기/웹 읽기는 M3 미리보기와 1회 승인 사용, 모델이 승인하지 못함. 승인 도구 ID와 작업 상태를 같은 DB transaction으로 저장한다.
4. 작업 관리 화면: 목표와 범위, 단계/도구/관찰, 승인 내용, 결과/검증, 일시중지/재개/취소. 재시작 시 자동 실행 안 함. 같은 경로/정체성의 폴더 재허용 후 재개. 불확실한 실행은 자동 재시도 금지. 계획·권한 실패는 명시적 재개로 최대 2회 복구, 읽기·비변경 도구 실패는 모델에 관찰을 주고 남은 예산 안에서 재계획. 파일 쓰기 실패는 결과가 불확실하므로 자동 재계획하지 않는다.
5. API/SQLite 재시작/승인 거절/동시 요청/공급자 동의/예산/결과 검증 테스트 먼저. 실제 배포 UI E2E와 독립 최종 검토. 외부 실 AI 키 없음은 미검증으로 유지.

검토 집중: 승인과 파일 실행 사이 크래시, 완료 영수증 뒤 체크포인트 누락, 중단 중 모델 응답 도착, 권한 재허용 범위 바꾸기, 결과 변조 시 성공 금지, 모델의 임의 도구/공급자 선택과 프롬프트 인젝션, 작업 결과의 외부 전송 동의.
